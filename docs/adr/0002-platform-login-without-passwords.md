# 以实验性扫码或登录 Cookie 导入建立平台会话

首期同时支持网易云音乐与 QQ 音乐，并允许操作者在公开获取不足、需要使用自身账号权益时建立平台会话；两家平台都没有可供第三方依赖的官方公开扫码 API，因此扫码仍是可随上游变化而失效的实验性适配器。网易云真实扫码闭环是本轮 NAS 发布完成条件：必须现场通过二维码生成、手机扫码、确认、状态轮询、会话加密保存和退出清除，返回 `503` 或只显示禁用入口均不算完成。已有有效会话时重新扫码，旧会话保留到新会话确认成功并验证有效后再原子替换；取消、过期或失败不影响旧会话。QQ 扫码不阻塞本轮发布，在 QQ 精确音质和下载签名验证后再独立验收；此前入口必须明确显示“尚未支持”。登录 Cookie 导入始终作为兜底：操作者只在工作台中粘贴本人已登录网页的 Cookie 请求头，系统永不接收或保存平台账号密码，也不伪造 IP、规避验证码或绕过风控。`musicdl` 只消费已有平台会话而不负责建立登录；各音乐源的登录适配器与下载适配器保持分离，QQ 登录不嵌入或复制 GPL 实现，同时必须检测会话有效性并允许操作者主动替换或清除会话。
