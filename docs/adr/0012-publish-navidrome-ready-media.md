# 发布 Navidrome 可直接索引的入库产物

服务器保存必须保留平台提供的原始音频编码而不转码，并在入库发布前尽力补全 `TITLE`、`ARTIST`、`ALBUM`、`ALBUMARTIST`、曲号、碟号和日期等 Navidrome 标签，同时将搜索结果使用的同一份已验证封面写入音频并保存为专辑 `cover.jpg`，另写音频同名 `.lrc`。浏览器取回至少保留音频内嵌封面。封面无法取得时不阻断已经验证的音频，但任务必须以“音频成功，封面缺失”明确告警。Navidrome 完全按标签组织曲库，因此下载器是媒体与标签的唯一写入者；所有可取得的标签和 sidecar 处理完成并校验后才原子发布到共享音乐库，Navidrome 始终只读扫描成品。
