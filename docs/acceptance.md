# musicdl-web 验收清单

## 自动化证据

- [x] 网易云与 QQ 的搜索、分页、来源隔离和稳定内部模型通过 fixture 契约测试（证据见 `docs/spikes/2026-07-31-search-metadata.md`）。
- [ ] 音质快照绑定平台会话版本与过期时间；请求与响应档位不一致时返回明确失败。
- [ ] 网络传输同时校验初始请求与重定向域名，拒绝第三方解析域名、关闭 TLS 验证和共享 Cookie。
- [ ] 实验性扫码状态机覆盖等待、已扫码、待确认、成功、拒绝、过期、取消和网络错误；终态清除临时令牌。
- [ ] 日志、异常、API、SQLite 和前端状态不含 Cookie、token、QR 内容或来源 URL。
- [ ] 会话密文可跨重启恢复，错误密钥安全失败，退出登录清除对应平台会话。
- [ ] 队列覆盖并发上限、取消、部分成功、失败重试、崩溃恢复和临时文件清理。
- [ ] 下载覆盖过期 URL、302 到禁用域名、HTML 响应、试听片段、截断文件、401/403 和音质降级。
- [ ] 媒体探测验证容器、codec、时长和所选音质；保留原编码且不转码。
- [ ] Navidrome 标签、内嵌封面、`cover.jpg`、同名 `.lrc`、路径规范化、冲突后缀和原子发布通过测试。
- [ ] 去重、音质升级、文件缺失和非受管文件保护通过回归测试。
- [ ] 浏览器取回逐文件交付且不写入入库索引；服务器保存正确写入 `/music`。
- [ ] Vue 工作台覆盖双来源分组、按需音质、短试听、跨组多选、队列操作与任务历史。
- [ ] 前后端类型检查、lint、单元测试、集成测试、生产构建和 Compose 配置校验全部通过。
- [ ] 容器以 UID/GID `1000:1000` 运行，健康检查监听容器端口 4534，数据与音乐库权限正确。

## 现场账号验收

- [ ] 在 NAS `.env` 显式启用实验性扫码；公开默认仍关闭。
- [ ] 操作者在 `http://192.168.50.10:4534` 页面亲自扫描网易云二维码，凭据不经过聊天或命令输出。
- [ ] 操作者以相同方式验证 QQ；扫码失败时验证手动会话导入兜底。
- [ ] 两个平台都能显示会话状态、执行搜索、按需列出当前会话可获取音质并播放合法短试听。
- [ ] 每个平台至少完成一首合法可获取歌曲的精确音质服务器保存；失败时展示可解释错误且不降级。
- [ ] 至少完成一次浏览器单曲取回和一次多曲逐文件取回。

## NAS 发布验收

- [ ] Y9000P 构建固定版本 `linux/amd64` 镜像并生成校验值。
- [ ] 镜像导入 NAS 后，`/data/docker/musicdl-web` 的 Compose 只启动本项目单容器。
- [ ] `http://192.168.50.10:4534` 健康可访问，重启容器后会话、队列和入库索引恢复。
- [ ] 成品写入 `/data/media/music`，Navidrome Compose、端口、数据卷和配置未被修改。
- [ ] Navidrome 通过现有 watcher 或一小时计划扫描发现入库歌曲，标签、封面与歌词正确。
- [ ] 部署后检查容器日志无秘密值、无持续错误，日志轮转、重启策略和 volume 均符合 NAS 约定。
- [ ] 保留上一版本镜像；新版本健康或关键流程失败时可以回退。

## 完成条件

只有双平台 spike、自动化门禁、Y9000P 构建、NAS 导入部署和现场账号验收全部通过，或任何无法执行的验证缺口被明确记录，才可宣称一期完成。
