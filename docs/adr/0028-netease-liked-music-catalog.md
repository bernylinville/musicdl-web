# 支持网易云账号「我喜欢的音乐」目录

在已建立网易云平台会话的前提下，操作者可以在工作台一键加载本人红心歌单（`specialType=5` 的「喜欢的音乐」），结果复用与关键词搜索相同的平台歌曲行、音质确认与批量下载路径。

本能力只覆盖网易云当前登录账号的喜欢目录；不解析任意歌单 URL、不整张专辑抓取、不提供跨账号或 QQ 侧对等目录。目录通过官方控制域 eapi（与扫码登录同一加密面）在服务端拉取，浏览器从不接收平台原始歌单地址或 Cookie。分页在服务端对缓存的全量列表切片；缓存随会话版本失效，TTL 约 5 分钟。

一期 ADR 0026 的「仅关键词搜索」边界在此被局部放宽：仍禁止任意歌单 URL 导入，但允许：

1. 与账号权益绑定的「我喜欢的音乐」只读目录；
2. 从结果行点击歌手 / 专辑 ID 进入该歌手或专辑的平台曲目列表（网易云），再沿用同一下载路径。
