# 双平台搜索元数据 spike

## 结论

网易云音乐与 QQ 音乐的“搜索不预解析下载 URL”fixture 契约已通过。两侧都曾在无 Cookie 请求中，从平台自有 HTTPS 主机取得搜索元数据并映射为 musicdl-web 的稳定内部模型；但 QQ 在独立验证代理的稍后复测中出现网络失败和平台业务码失败，随后根代理连续三次复测又恢复成功。因此 live 可用性只能判定为不稳定，不能作为正式开发准入证据。

这不是完整双平台准入结论，也不是搜索能力的稳定性承诺。逐歌曲当前会话音质、精确单档解析、下载前重验、短试听、媒体校验与自有账号权益路径仍未通过，因此完整工作台和下载执行层仍保持关闭。

覆盖范围：

- 拒绝第三方主机、HTTP、URL 凭据和跨白名单重定向。

- 平台错误码与异常被归一化，不在错误中暴露 URL 或查询参数。

## 未公开接口风险

当前适配器验证的是平台自有但未公开承诺的 Web 私有端点：

- 网易云音乐：`POST https://music.163.com/api/cloudsearch/pc`
- QQ 音乐：`POST https://u.y.qq.com/cgi-bin/musicu.fcg`

官方 Web 页面当前使用的协议可能不同：网易页面可走加密 `weapi`，QQ 页面可能要求登录并走带动态签名的 `musics.fcg`。因此本次结果只证明上述请求在验证时点可用，不能视为平台提供的稳定公共 API。适配器保留为可替换 spike，不承诺兼容性；任何响应形态变化都必须明确失败并重新验证，不能切到第三方解析或关闭 TLS。
