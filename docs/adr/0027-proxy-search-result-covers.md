# 通过同源代理交付搜索结果封面

搜索结果必须显示小尺寸封面，但浏览器不得直接接收或请求音乐源的原始图片地址。musicdl-web 通过同源接口代理封面，并在后端强制执行平台图片域名白名单、HTTPS、重定向检查、响应类型与大小限制及短期缓存，以保留来源 URL 隔离边界。同一份已验证图片用于搜索展示、音频内嵌封面和服务器专辑 `cover.jpg`；浏览器取回至少保留音频内嵌封面。封面只是辅助识别信息：单张图片失败只让对应歌曲显示占位符并允许重试，不得让歌曲、整组搜索或已经验证的音频下载失败，但下载结果必须明确告警“音频成功，封面缺失”。
