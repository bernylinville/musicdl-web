# 以实验性扫码或手动导入建立平台会话

首期同时支持网易云音乐与 QQ 音乐，并允许操作者在公开获取不足、需要使用自身账号权益时建立平台会话；两家平台都没有可供第三方依赖的官方公开扫码 API，因此扫码只能作为依赖非公开 Web 行为、可随时关闭的实验性适配器，公开 Compose 默认关闭而操作者的 NAS 可显式开启。手动导入既有 Cookie 始终作为兜底，系统永不接收或保存平台账号密码，也不伪造 IP、规避验证码或绕过风控。`musicdl` 只消费已有平台会话而不负责建立登录；各音乐源的登录适配器与下载适配器保持分离，QQ 登录不嵌入或复制 GPL 实现，同时必须检测会话有效性并允许操作者主动替换或清除会话。
